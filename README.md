Don Família - Cardápio Online (V40)

COMO COLOCAR NO AR (GitHub Pages)
1. Extraia o .zip no celular ou no computador (não suba o .zip em si).
2. No GitHub, abra o repositório do site e APAGUE os arquivos antigos
   (inclusive "Don-Familia-WEB-OTIMIZADO.mp4" e "assets/menu-01.png", se existirem).
3. Envie TODOS os arquivos desta pasta, mantendo a pasta "assets" e o arquivo ".nojekyll".
4. Espere de 1 a 3 minutos e abra o link do site.
5. Faça um pedido de teste e toque no link "Imprimir pedido" que chega no WhatsApp.

ARQUIVOS (todos são necessários)
- index.html ........................ o site (cardápio, carrinho e pedido pelo WhatsApp)
- recibo.html ....................... página do cupom para imprimir o pedido (abre pelo link do WhatsApp
                                      ou, se o link vier cortado, cole o texto do pedido na caixa da página;
                                      tem botões Imprimir, Baixar PDF e Baixar .txt)
- Don-Familia-Novo-Ambiente.mp4 ..... vídeo da loja (1080p, 60 fps, ~21 MB)
- assets/ ........................... imagens do cardápio
- .nojekyll ......................... necessário para o GitHub Pages
